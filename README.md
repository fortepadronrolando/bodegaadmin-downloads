# BodegaAdmin — Descargas

Aplicación para la gestión de mipymes, bodegas y tiendas: inventario por almacenes, punto de venta, catálogo en línea y reportes.

**Versión web:** https://bodegaadmin-frontend.vercel.app

## Descargar la última versión

| Plataforma | Archivo |
|---|---|
| Android | [app-release.apk](https://github.com/fortepadronrolando/bodegaadmin-downloads/releases/latest/download/app-release.apk) |
| Windows | [bodegaadmin-windows.zip](https://github.com/fortepadronrolando/bodegaadmin-downloads/releases/latest/download/bodegaadmin-windows.zip) |
| GNU/Linux | [bodegaadmin-linux.tar.gz](https://github.com/fortepadronrolando/bodegaadmin-downloads/releases/latest/download/bodegaadmin-linux.tar.gz) |

### Instalación

- **Android:** abre el `.apk` y permite instalar desde orígenes desconocidos si te lo pide.
- **Windows:** descomprime el `.zip` y ejecuta `bodegaadmin_frontend.exe`.
- **GNU/Linux:** descomprime y ejecuta `./install.sh` para añadir el ícono al menú de aplicaciones.

Este repositorio solo contiene los binarios, que se publican automáticamente desde GitHub Actions en cada nueva versión.
